Loan EMI & Eligibility Calculator

Open loan_eligibility_calculator.html in Chrome/Edge/Firefox. No server or internet connection is required.

Inputs: monthly income, existing EMI, loan amount, tenure, interest rate, credit score.
Outputs: EMI, FOIR, condition status, eligibility and rejection reason.

Baseline rule: FOIR <= 50% AND Credit Score >= 700.

Validation blocks negative values, non-positive income/tenure, invalid rates and credit scores outside 300–900.

This is an educational prototype, not a production underwriting system.
